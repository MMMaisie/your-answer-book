# v49.5 整合版

这是包含运行代码、模板、静态图片、字体、知识资料和测试的完整覆盖包，
包含 v49.4.1–v49.4.6 的修复，以及本次确认的话术与首页介绍。

## 部署
1. 解压，将文件复制进现有 your-answer-book 仓库根目录，替换同名文件。
   根目录应直接看到 app.py、requirements.txt、templates、static、knowledge。
   不要把整个目录再嵌套一层；不删除 .git、不清数据库、不覆盖线上环境变量。
2. GitHub Desktop Commit、Push。等待 Render 部署完成。
3. 启动命令维持 gunicorn guaxiang:app；环境变量沿用原来已经跑通的配置。
4. /healthz 的 version 前缀应是 v49.5-reader-home-。

## 内容与首页
- 免费：判断＋一个关键点，中文不超过50字，不展开整套原因和建议。
- 付费：直接回答、白话解释关键原因、说明改变判断的条件；中文合计不超过300字。
  专业依据最多选一处一句带过，不让客户先理解世应生克才能看懂。
- 不将传统象意断言为已发生的房屋、产权、债务、第三者或健康事实。
- 首页显示已确认的九类话题、简介、提问示例；英文对应更新。
- 不显示用户已删除的健康/生育说明。
- 示例解读也改为简短初判和白话完整解释。
- 问意提示细分买入、成交、卖房、租住、修造等，只辅助参考，不硬编码取用或吉凶。

## 已保留的修复
- 初判含术语：内部事实和依据通过后，仅改写初判一句话；最多两次请求。
- 文案错误给模型针对性修正，不整段截断，不用假解读或模板冒充成功。
- 付款授权和已保存解读继续保留，正文重试复用已保存的复核记录。
- 初判失败不再误称付款有效。
- 认证私密测试跳过免费次数、间隔、日费用、调用次数、全站并发和联网次数限制。
  需沿用 PRIVATE_TEST_UNLIMITED=1、STRIPE_MODE=test、正确tester密码。
  不要把 environment.example.txt 的占位值导入已有线上配置。
  身份验证、付款授权、事实检查、同卦防重复任务和总停用开关保留。
  真实API调用仍计费。
